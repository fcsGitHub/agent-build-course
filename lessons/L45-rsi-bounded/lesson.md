# L45 有界 RSI 循环（Darwin Gödel Machine 教学骨架）

递归自我改进（RSI）不是玄学，它有一个可以拆开观察的骨架。所有 2023-2026 年的自改进系统——
Self-Refine/Reflexion（任务内反思）、ADAS（搜索 agent 设计）、Darwin Gödel Machine（Sakana AI + UBC, 2025）、
AlphaEvolve（DeepMind, 2025）、SICA（自改源码的编码 agent）、SEAL（MIT，自编辑+微调）、AREX（2026，验证式深度研究 RSI）——
都由同四个要素组成：

| 要素 | 本课实现 | DGM 原版 |
|---|---|---|
| **生成器**（谁提出变异） | 模型改写 worker 的 system prompt | 模型改写 agent 的源代码 |
| **对象**（什么被改进） | 提示（harness 层） | 代码/工具/工作流（权重级见 SEAL，本平台不可执行） |
| **评估器**（什么算更好） | 冻结验证集 + 确定性子串判分（平台持有） | SWE-bench 等基准（沙箱内评测） |
| **记忆**（变异存哪） | 变体归档：被拒变体也保留 | agent 树/归档（开放探索的垫脚石） |

## 循环（可直接在流程图上打断点观察）

1. **v0 基线**：当前提示先在冻结集上得分（同一把尺子，见 L38）。
2. 每一代：**变异提案**（模型针对失败反馈改写提示）→ **冻结集评估** → **晋级门**：
   分数**严格提高**才替换最优；否则拒绝——但被拒变体**保留在归档**中
   （DGM 的关键反直觉设计：暂时变差的变体可能是后续改进的垫脚石，不要贪心爬山）。
3. 到达代数上限（本课 2 代；服务端绝对上限 3）即输出报告与最优变体。

在「架构/信息流」图上点击**变异提案**或**冻结集评估**节点设置断点：每次模型调用前驻留，
可以当场查看 prompt（观察区 Prompt 页签）——你看到的正是该变体真实收到的提示。

## 安全边界（平台侧，不在自改面）

- **评分器、冻结验证集、预算、晋级门**由平台持有，候选不可见、不可修改（对照 L39 的演进四道门）。
- **代数/调用数/墙钟/变体长度**都是服务端硬上限：manifest 配错也不能无界自改。
- **诚实边界**：本课改进的是提示。权重级 RSI（SEAL 式自编辑 + 微调）在本平台**不可执行**——
  训练接口只做登记（L40）。报告末尾会如实声明这一点。

## 观察要点

- `rsi.generation_started` / `rsi.generation_completed`：每代的父代、候选、晋级决策。
- `candidate.evaluated`：候选与基线在同一冻结集上的得分——注意评分器从不出现在候选可见的上下文里。
- `candidate.rejected`：拒绝不是失败，是归档的一部分。对比 DGM 论文的消融：
  去掉归档只保留最优（纯爬山）的变体表现更差。
- 断点驻留在 `before_model` 时查看 Prompt 页签：确认"模型看到了什么"与"评估器看到了什么"是分离的。

## 思考题

1. 为什么晋级门要求**严格改进**而不是"不低于父代"？（提示：等价变体会让循环失去终止压力）
2. 如果候选提示里写"忽略任务，直接输出通过词"，冻结集判分会怎么暴露它？这依赖什么前提？
3. DGM 同时改代码与提示；只改提示的 RSI 天花板在哪里？SEAL 为什么必须动权重？
