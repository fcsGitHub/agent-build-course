# L01 Prompt 是输入，不是魔法

## 机制

Prompt 是一次模型调用输入组织的一部分。本课开放课程 Prompt 的**任务说明区域**：
你可以在前端创建个人草稿、修改文本、保存并通过校验，然后用新版本发起一次真实运行。

## 观察点

1. 打开"源码"页签：`运行快照` 显示本次执行的版本；`个人草稿` 显示可编辑副本；`差异` 对比两者。
2. 修改 prompt 后保存 → 校验（不调用模型）→ 采用版本 → 自己发送任务。
3. 对照两次运行：`context.compiled` 事件携带编译后的完整消息，diff 一目了然。

## 诚实的结论

prompt 变化带来的是输入变化；两次输出不同不代表模型"变聪明了"。
同参数重复调用也不保证相同输出（服务端采样），课程不承诺输出一致。
