# L35 外部化长输入与有界递归

上下文放不下/不该放下的长输入怎么办？本课执行真正的递归语言任务：

1. **外部化**：长手册一次性进入 blob 存储；事件只引用不内联。
2. **递归树**：分区过大且未到深度上限 → 行边界二分；叶子分区回答"维护要点"问题；内部节点合并子回答。
3. **有界**：深度上限 = min(manifest.max_depth, 服务端硬上限 8)；节点数硬上限 64；超限分区诚实标记 truncated（覆盖不完整），不冒充完整。
4. **子调用预算**：每个节点的一次模型调用从父预算**原子预留**（与 L31 同一 BudgetLedger 行）；不足的节点显式 BUDGET_EXCEEDED，最终答案声明缺失分区。

## 观察要点

- `recursion.node_started/node_completed` 带 depth/label/usage：递归树是可见的数据结构，不是黑盒。
- 对照 L15（压缩）：压缩丢弃内容，递归分区不丢——代价是更多调用与更长墙钟。
- 失败模式：预算不足 → 部分分区缺失且最终答案声明；这优于"看起来完整"的幻觉汇总。
