# L00 第一次真实模型调用

## 你将看到什么

这是 AgentGlass 的第一个实验。打开本页面**不会**向任何模型发送请求。
只有当你在输入框写下自己的任务并点击"发送"后，系统才会创建一次真实运行。

## 观察点

1. **配置快照**：本次运行使用的模型端点、模型 ID、能力探测结果在顶部常驻显示。
2. **请求证据**：`model.request_prepared` 事件携带序列化后、脱敏前的出站载荷（已去除凭据）。
3. **响应与用量**：`model.response_completed` 显示结束原因与 token 用量；未配置价格表时费用显示"未知"。
4. **错误也是证据**：未配置模型时无法发起实时运行；调用失败会记录真实错误，不会变成演示文本。

## 练习

- 不使用提示卡，自己写一个任务并发送。
- 在检查器"信息流"页找到这次运行的模型调用边，点开请求载荷。
- 回答：你的输出文字来自哪里？是页面预先写好的，还是模型返回的？
