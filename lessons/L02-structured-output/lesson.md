# L02 合法 JSON 与语义正确不是同一件事

## 机制

结构化输出 = 模型被要求输出符合 schema 的 JSON。系统对 JSON 做**确定性 schema 校验**；
校验失败可按课程策略发起一次显式修复请求 —— 修复本身是一笔新的真实调用，独立计费。

## 观察点

1. 发送要求 JSON 输出的任务；检查 `model.response_completed` 的原始文本是否可解析。
2. 校验失败时系统追加修复请求：比较两次调用的输入差异与费用。
3. 结论分层：JSON 可解析（语法）→ 字段符合 schema（结构）→ 内容正确（语义）。三者互不等价。

## 练习

自己写一个"要求输出 {物品, 数量} JSON"的任务，故意要求一个模型无法满足的字段，
观察校验错误与修复行为。
