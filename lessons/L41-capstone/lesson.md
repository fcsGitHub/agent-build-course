# L41 毕业实验：带证据的研究与文档 Agent

毕业评分重点不是组件数量，而是：任务是否完成、证据是否可靠、边界是否清楚、失败是否可解释。

本课在一个 run 内综合：

- **检索与读取**：read_text 读取研究笔记与库存数据（引用真实文件内容）。
- **计算**：calculator 产出可复算的数字证据（库存总量）。
- **高影响写入**：write_file 走具体效果审批（awaiting_approval 驻留 → 用户批准 → 真实写入 run 专属工作区）。
- **可回放**：run 结束后导出 `.agtrace.zip`，断网回放（回放不执行任何代码）。

## 通过标准（对照账本自查）

1. 最终回答中的每个数字都能在 tool.call_completed 中找到来源。
2. 写入发生在 approval.granted 之后（时间戳可查）。
3. 停止原因是 final_answer，而非预算截断。
4. 运行包可在离线环境完整回放。
