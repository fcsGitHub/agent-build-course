# L04 模型调用工具 ≠ 工具已执行

## 关键事件

1. `tool.proposed`：模型响应中的工具参数只是**请求**。此时什么都没发生。
2. `tool.validated`：宿主校验参数 schema 与白名单（工具描述不能自授权限）。
3. `tool.call_completed`：工具代理执行完毕，产生结果工件；完整内容存工件，进上下文的部分截断并标注。
4. 下一轮 `context.compiled` 中，工具结果作为 tool 消息进入模型可见上下文。

## 故障与干预

- 工具不在白名单 → `tool.denied`（TOOL_NOT_ALLOWED），模型收到拒绝原因。
- 参数不是合法 JSON → 拒绝执行并把错误反馈给模型。
- 数据文件改列名 → 真实解析错误进入事件记录（失败也是可回放证据）。

## 通过条件

你能指出"请求"与"执行"两个事件；找到第二轮新增的 tool 消息；
最终回答引用的数值能对上计算器结果。
