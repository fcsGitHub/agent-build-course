# L05 观察与行动循环（本课旗舰练习）

## 机制

Agent 与一次工具调用的差别在循环：观察 → 决策 → 行动 → 新观察。
参考内核每个轮次结束时调用你修改的 `shouldContinue`（在隔离进程中真实执行）；
返回 true 只是**请求**继续，宿主仍执行硬预算（maxTurns / maxModelCalls / 超时）。

## 代码练习（A15 验收路径）

1. 打开"源码"页 → 从运行快照创建个人草稿。
2. 把 `shouldContinue` 中的 `< 3` 改成 `< 5`，保存 → 校验（零模型调用）→ 采用版本。
3. 自己输入任务并发送（或明确选择"用上次输入对照运行"）。
4. 对照：`policy.stop_decision` 事件、实际轮数、停止原因、总成本。

## 诚实的结论

- 任务本来一轮就完成时，两版轨迹可以完全相同 —— 这也是有效实验结果。
- 增加轮数上限不保证更高完成度，只保证更大概率更多成本。
- 函数忙等或返回非法类型 → 记录策略错误并终止客体，不会静默继续。

## 通过条件

能指出：代码改了哪条决策条件、影响了哪个调用边、宿主硬边界在哪里。
