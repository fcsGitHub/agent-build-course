# L07 并行是调度属性，不等于多 Agent

## 机制

一次模型响应可以提出多个工具请求。工具代理按 run 预算的 max_concurrency 并发执行；
每个调用有独立事件与工件。**并行**只是同一 run 内的调度方式；
没有独立上下文与任务边界，就不是多 Agent（那是 L30 的主题）。

## 观察点

1. 同一轮多个 `tool.proposed` 事件的顺序（模型给出的顺序）。
2. `tool.call_completed` 的完成顺序可能与请求顺序不同。
3. 下一轮上下文中，工具结果按提供方协议要求的消息顺序入上下文（成组完整）。

## 练习

要求模型同时读取两个季度的销售文件并计算总和；
对比在 L04（单个文件）与这里（多个文件）的事件时间轴。
