# L16 记忆有生命周期与作用域

工具 `remember` / `recall` 背后是真实记忆服务：
- 作用域独立字段（本课为 user:local-learner），他人不可见、不可删；
- 相同内容幂等；内容变化产生新版本（previous_id 链）；
- **遗忘是传播的**：删除后 recall 与列表都不再返回（A14）。

## 实验

1. "请记住：我先看结论再看依据。" → 观察 remember 工具卡与 memory_id。
2. "我的输出偏好是什么？" → recall 命中。
3. 用 API 删除该记忆 → 再次 recall：应无命中。
4. 在另一用户作用域（API 指定 scopeId）验证读不到你的记忆。

## 结论

聊天历史是"发生过什么"；记忆是经过选择、作用域与生命周期管理的数据——两者不是一回事。
