# 教师指南（L00—L45 全量 46 门；阶段 IX 前沿与 RSI）

## 课前准备

1. `pnpm install && pnpm build`，然后分别启动 API 与 worker（见 README 快速开始）。
2. **无网络课堂**：使用 `AGENTGLASS_SEED_FAKE=1` 的模拟模型即可完成 L04—L07 的完整工具循环；运行证据在 UI 显式标注"模拟"。L00—L03 的"真实模型"体验需要可访问的 openai-compatible 端点。
3. **真实模型课堂**：设置页添加端点 → 点击「探测」→ 查看能力报告（流式/工具/结构化/用量）。探测消耗少量真实额度，请提前告知。

## R5 课程（L42/L43/L44/L45）的课前准备

阶段 IX 是前沿扩展阶段（设计文档 §4 之外的 R5 增补）。L42 需要真实模型（简报在 system prompt，一问一答，无工具）；无网络课堂可跳过或用 fake 模型但回答质量有限（UI 会显式标注"模拟"）。L43/L44 首次运行时 worker 幂等摄取课程文档资产（同知识课）。L45 是核心课：先讲 lesson.md 的四要素骨架，再让学生发送一个改进目标；建议同时打开「信息流」图并在「变异提案」「冻结集评估」节点上设断点——驻留时到 Prompt 页签查看该变体真实收到的提示。fake 模型（forceAnswer）在 L45 的变异输出没有 <prompt> 标记，两代都会 INVALID_MUTATION 被拒：这本身就是教学点（诚实拒绝），要看到真实的改进循环需要接入真实模型。

## R4c 课程（L33/L34/L35/L38/L40/L41）的课前准备

L33 启动本地 A2A agent 桥（`packages/a2a/src/course-agent.mjs` 子进程 + 回环 HTTP），远端 artifact 一律标注"待验证信息"。L34 用同一任务文本在 L34/L08/L20/L31 四门课各运行一次，历史页逐项对比费用（usage）、延迟与停止原因——样本量 1 只描述该对，不宣称统计显著。L35 的长手册在 blob 外部化，递归树每个节点的事件带 depth/usage；可现场把 max_model_calls 调小，观察 BUDGET_EXCEEDED 节点与"覆盖缺失"的诚实声明。L38/L39 门控在服务层/测试覆盖（tests/contract/evolution-r4c.spec.ts、tests/integration/r4-reflection-promotion.spec.ts）。L40 训练能力本地模式**如实禁用**：任务停在 unsupported，不可标注"本次训练完成"——这是设计行为（§4.10 能力降级），请向学生说明这不是缺陷。L41 毕业链需要教师掌握审批决策命令（同 L21）；通过标准在 lesson.md，学生对照账本自查。

## R4b 课程（L27/L28/L29）的课前准备

L27 使用本地 http 夹具演示受控联网：域名白名单外的请求显式 SSRF/host 拒绝，抓取内容带 untrusted-content 标记。L28 的注入素材位于 `datasets/injection-demo/faq-injected.md`（HTML 注释里的 write_file 指令）——这是教学素材，请向学生说明为什么 write_file 零触发。L29 使用确定性故障 runner 演示评测：错误用例显式"执行失败"，不给假成功（tests/contract 覆盖远程 MCP HTTP 与 A2A 协议）。

## R4 课程（L36/L37/L39）的课前准备

L36 依赖 chain 反思注入（manifest reflection_on_failure: true）。L39 门控演示在服务层/测试覆盖（tests/integration/r4-reflection-promotion.spec.ts），课堂用 list_skills/load_skill 展示当前版本。

## R3b 课程（L25/L26）的课前准备

L26 工作区项目位于 `datasets/sandbox-project/`（含 bug 的 format.js + 三断言测试）。run_test 为 PATH-only 子进程 + SIGKILL 硬超时；教师可演示忙等脚本被终止。写入补丁仍走审批（awaiting_approval 驻留）。

## R3 课程（L30—L32）的课前准备

多 Agent 课在单 run 内产生多个子调用：子 agent 上下文隔离（只见任务包）、预算原子共享。L31 可把 max_model_calls 调至 2 重跑，观察第三个 worker 被预算拒绝（BUDGET_EXCEEDED）。

## R2b 课程（L22—L24）的课前准备

## 每门课的教学节奏（统一闭环）

1. **打开课程**：实验台输入框为空。向学生强调：此时零模型调用（可在设置页关闭网络演示验证）。
2. **自由提问**：学生自己写任务；提示卡只是草稿素材，不强迫使用。
3. **预测**：发送前让学生预测下一个事件（会请求哪个工具？上下文会增加什么？何时停止？）。
4. **观察证据**：中栏时间轴点开工具卡 → 右侧「上下文」查看该次调用模型实际收到的消息；「信息流」看真实调用边。
5. **修改开放代码**（L01/L05/L06）：源码页签 → 改函数体 → 保存（零调用）→ 校验（零调用）→ 采用 → 重新发送对照。
6. **解释差异**：对照 `policy.stop_decision`、轮数、预算用量与最终回答。注意：没有差异也是有效结论。

## 各课要点

| 课 | 演示焦点 | 常见学生问题 |
|---|---|---|
| L00 | 输出来自哪里；请求/响应/用量证据 | "模型说的是真的吗？"——引用证据，不引述自述 |
| L01 | prompt 是输入不是魔法；编译消息 diff | 两次输出不同 ≠ 模型变聪明 |
| L02 | JSON 可解析 ≠ 字段符合 schema ≠ 语义正确 | 修复请求是一笔新的真实调用 |
| L03 | 中断不是完成；finishReason 是权威 | 截断（length）与 stop 的区别 |

| L05 | shouldContinue 在隔离进程真实执行；宿主硬预算不可突破 | 改 `<3→<5` 后轨迹可能完全相同（任务一轮就完成） |
| L06 | 软策略 vs 宿主硬上限；失败也是可回放证据 | 被终止 ≠ 任务成功 |
| L07 | 并行是调度属性，不是多 Agent | 同一 run 内的并发 ≠ 独立上下文 |
| L08 | 固定工作流 vs 自主循环：控制权与成本 | chain 固定 3 次调用，loop 次数由观察决定 |
| L09 | 文档 → 块 → 索引的流水线与版本绑定 | 相似度分数 ≠ 答案正确概率 |

## 演示脚本（评审/公开课 10 分钟）

1. 打开 L05，输入框为空 —— 打开 DevTools 网络面板证明零模型请求。
2. 插入提示卡（不发送），再清空，自己输入任务发送 —— 真实运行，工具卡逐个点亮。
3. 点开 `tool.call_completed` → 上下文页签看到工具结果进入下一轮。
4. 源码页改 `shouldContinue` 的 `< 3` 为 `< 5` → 保存 → 校验（强调零调用）→ 采用 → 再次发送。
5. 历史页勾选两次运行「对照」—— 输入/代码/停止原因/成本逐项对比。
6. 导出 .agtrace.zip → 断网 → 回放页导入播放 —— 全程零外部请求。

## 安全边界讲解要点

- 学生代码运行在无秘密的隔离子进程；忙等会被杀死（可演示：函数体写 `while(true){}`，校验直接拒绝）。
- 修改平台保护文件（如预算常量）会在服务端 AST 检查被拒（EDIT_OUTSIDE_ALLOWED_SCOPE）。
- 工具不在课程白名单 → `tool.denied`；工具描述再"友好"也不能自授权限。
